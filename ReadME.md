# Cos'è la Burrows Wheeler Transformation?

La BWT non comprime direttamente i dati, ma riorganizza i caratteri di una stringa in modo da raggruppare simboli identici in sequenze contigue 

# Esempio di trasformata
Input: $Banana
Output: annb$aa

# Come utilizzare il programma
Avviare il server (py Server.py)
Avviare il client (py Client.py)
Verrà richiesto di inserire una stringa sulla quale applicare una trasformata
Verrà mostrato in output la trasformata
